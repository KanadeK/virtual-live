# 竖屏舞台与指标

默认场景为中性虚拟主播工作室，1080×1920，分为背景、角色、前景、UI。头像及标题可通过源码配置替换；发行版不包含个人形象或直播截图。

- 鱼干：`FISH_ROOM_ID` 未配置时未知；初始余额默认 0，仅对匹配房间的真实、有效 gold 礼物 `total_coin` 去重入账。silver 不折现，累计 COMBO 不重复入账，缺金额不假填 0。
- 费用：实际用量乘已配置模型对应费率的估算，UI 显示 ×3，原始账本与预算不变。不是实际扣款，未扣优惠和免费额度；不支持的用量显示未知。
- 本次聊过天：当前实际采集范围去重，不含 Mock、本机注入、历史或重复事件，不代表全天。

点歌的队列、加载和实际播放状态分别保留，主播播报期间按实际语音开始与结束回执降音和恢复。`preview=1` 为静音只读预览，不能取得主播租约。
